🚀 Features

- 🧑‍💻 About Me section
- 📄 Resume download/view
- 💼 Projects showcase
- 🛠️ Skills section
- 📬 Contact form / details
- ⚡ Fast and optimized performance


🛠️ Tech Stack

- **Frontend:** Angular
- **Styling:** CSS / SCSS
- **Deployment:** Netlify
- **Version Control:** Git & GitHub


⚙️ Installation & Setup

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/prudeep/prudeep-portfolio.git

# Navigate into project
cd prudeep-portfolio

# Install dependencies
npm install

# Run the app
ng serve
